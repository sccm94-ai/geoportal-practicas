Objetivo

Presentar un geoportal web funcional que permita visualizar capas geográficas publicadas desde un GeoServer, descargar la información en varios formatos interoperables y ofrecer una interfaz clara para navegación, consulta y contacto.

Visualización y cambio de imagen WMS

Usa los botones para mostrar cada capa simbolizada y también la composición de las 3 capas.

Selecciona una capa para generar la imagen WMS.
Este bloque genera una imagen WMS directamente desde GeoServer mediante GetMap. Para que se vea correctamente en GitHub Pages, el servicio debe estar disponible por HTTPS.

Descarga de capas desde GeoServer

Cada capa puede descargarse en Shapefile, KML y GML usando servicios WFS del GeoServer de IDESINDE.

En GeoServer, el formato Shapefile usualmente se descarga como archivo ZIP. KML y GML dependen de que el servicio WFS del servidor tenga habilitados esos formatos de salida.

Visor cartográfico en OpenLayers

Mapa base OpenStreetMap con la composición WMS, barra de escala y coordenadas en latitud/longitud.

El visor carga OpenStreetMap como fondo y la composición de capas publicadas en el servidor. Si tienes creado un layer group en GeoServer, puedes usarlo como composición; si no, el sistema dibuja las tres capas a la vez.
